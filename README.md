# Счётчик рядов для вязания

Веб-приложение для телефона: один общий счётчик рядов изделия и до 10 циклических счётчиков паттернов, которые двигаются вместе с ним.

## Как запустить

Из папки `D:\my\lessons`:

```bash
python -m http.server 8080 --directory knit-counter
```

Затем открой в браузере http://localhost:8080.

> Просто открыть `index.html` двойным кликом тоже можно, но тогда не заработает офлайн-режим: service worker работает только через `http://`.

## Из чего состоит

| Файл | Зачем |
|---|---|
| `index.html` | Разметка: что есть на странице (шапка, счётчик, кнопки, окно настроек) |
| `style.css` | Внешний вид: цвета, размеры, раскладка, тёмная тема |
| `app.js` | Логика: данные, подсчёт, обработка нажатий |
| `manifest.json` | Описание приложения для установки на домашний экран телефона |
| `sw.js` | Service worker: кэширует файлы, чтобы приложение работало без интернета |
| `icon.svg` | Иконка |

## Главная идея логики

Хранится **только номер текущего ряда изделия**. Ряд каждого паттерна вычисляется формулой:

```
пройдено = ряд_изделия − ряд_старта_паттерна
ряд_паттерна = (пройдено % высота) + 1
повтор = floor(пройдено / высота) + 1
```

`%` — остаток от деления. Именно он даёт цикл: для высоты 4 ряды идут 1, 2, 3, 4, 1, 2, 3, 4…

Почему так, а не отдельный счётчик для каждого паттерна:
- счётчики **не могут рассинхронизироваться**, все они следуют из одного числа;
- кнопка «−1» откатывает все паттерны правильно, ничего не нужно помнить;
- если поменять высоту паттерна в настройках, всё сразу пересчитается.

Пример (A = 4, B = 6, C = 17, все с 1-го ряда), ряд изделия 18:
A = 17 % 4 + 1 = **2**, B = 17 % 6 + 1 = **6**, C = 17 % 17 + 1 = **1** (начался второй повтор C).

## Где хранятся данные

В `localStorage` браузера (ключ `knit-counter-v1`), то есть на самом устройстве. У каждого браузера и каждого телефона данные свои. Если очистить данные сайта, они пропадут.
